# Planche

Lecteur de bandes dessinées, mangas, PDF et EPUB pour Windows, Linux et macOS (Tauri : Rust + React). Il reprend les fonctions de l'application Cover et ajoute les annotations, la lecture à voix haute, les catalogues OPDS, 27 langues d'interface et une bibliothèque chiffrée.
